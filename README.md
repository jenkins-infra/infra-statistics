# Jenkins Usage Statistics

This pipeline publishes data from existing usage/census files collected by the jenkins.io infrastructure.
More specifically:

- http://old.stats.jenkins.io/ (branch `gh-pages`) also used as reference statistics data
- http://stats.jenkins.io/ (repository: https://github.com/jenkins-infra/stats.jenkins.io)

See https://github.com/jenkins-infra/helpdesk/issues/4666 for details
